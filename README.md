## 📌 Sobre o Repositório

Este repositório registra minha jornada de aprendizado prático nos fundamentos do sistema operacional Linux, utilizando a distribuição **Zorin OS Core** em um laptop **Dell Vostro 14-5480**.

O objetivo é documentar comandos essenciais, conceitos de linha de comando (CLI), gerenciamento de arquivos, permissões e práticas de administração de sistema.

---

| **Sistema Operacional** | Zorin OS |
| **Arquitetura** | x86_64 |

| **Terminal** | GNOME Terminal |

## 🎯 Conteúdos Estudados

- [x] **Navegação e Sistema de Arquivos** (`ls`, `cd`, `pwd`, `tree`)
- [x] **Manipulação de Arquivos e Diretórios** (`mkdir`, `touch`, `cp`, `mv`, `rm`)
- [x] **Visualização e Edição de Texto** (`cat`, `less`, `nano`, `grep`)
- [x] **Permissões e Usuários** (`chmod`, `chown`, `sudo`, `useradd`)
- [x] **Gerenciamento de Pacotes** (`apt`, `dpkg`, `flatpak`)
- [x] **Rede e Processos Básicos** (`ping`, `curl`, `ps`, `top`, `kill`)
